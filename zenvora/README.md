# ZENVORA — premium pillow storefront

React 19 + TypeScript + Vite · Tailwind CSS v4 · shadcn/ui (Base UI) · Motion

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
```

- 8 products across Cervical, Luxury, Cooling and Travel; product art is generated SVG (no external images)
- Cart (persisted in localStorage), wishlist, search (⌘/Ctrl+K), filters, sorting, coupon `ZEN10`
- India (INR, GST-inclusive, COD) + 7 international regions with local currency, shipping and delivery rules
- Checkout is a demo: no payment is processed. Connect Razorpay (India) / Stripe (international) when ready.
- Review content is sample data.
